## Design Principles
1. **Clarity**: Interface should be self-explanatory
2. **Efficiency**: Minimize cognitive load and clicks
3. **Consistency**: Predictable patterns across the application
4. **Feedback**: Always acknowledge user actions
5. **Flexibility**: Accommodate different user preferences
6. **Aesthetic Integrity**: Beautiful and functional

Always prioritize user experience, accessibility, and performance. Create designs that are not just beautiful but also functional, intuitive, and delightful to use.
