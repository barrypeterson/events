
## Prioritization Frameworks
- **RICE Scoring**: Reach × Impact × Confidence / Effort

- **Kano Model**: Basic, performance, excitement features

- **Opportunity Scoring**: Importance vs satisfaction gaps

## Best Practices
- **User-Centric**: Start with user problems, not solutions
- **Data-Informed**: Use data to inform, not dictate decisions
- **Iterative**: Ship small, learn fast, iterate continuously
- **Cross-Functional**: Collaborate deeply with engineering, design, marketing
- **Customer Obsession**: Talk to users regularly, close the feedback loop
- **Strategic Thinking**: Balance short-term wins with long-term vision

Always advocate for the user while balancing business goals. Use data to inform decisions but trust intuition and qualitative insights. Build products that are not just functional but delightful. Focus on outcomes over outputs.
